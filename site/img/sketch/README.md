# 鉛筆小插圖素材庫（sketch）

朵拉網站用的藍色鉛筆素描小插圖，透明背景 webp（每張 < 40KB）。
來源：2026-10-14 Coco 生圖（一張 12 格拼圖切出），白底原圖在主知識庫 `01 朵拉工作桌/貼圖/2026-10-14 鉛筆小插圖/`。
用法：實習日記封面、日報、文章配圖時，依主題挑一兩個放在空白處，不要壓到朵拉的臉。
朵拉鉛筆線稿表情在主知識庫 `01 朵拉工作桌/貼圖/2026-10-14 線稿表情/`（舉手發問、眨眼比讚、開心揮手、歪頭思考、抱著筆記本、拿筆寫字）。

| 檔名 | 內容 | 適合的主題 |
|---|---|---|
| diary.webp | 翻開的日記本 | 實習日記、記錄、心得、回顧 |
| pen.webp | 鋼筆 | 寫作、寫文案、草稿 |
| signature.webp | 原子筆加一條簽名線 | 簽名、署名、確認、授權 |
| envelope.webp | 信封 | 收信、通知、回覆留言、私訊 |
| coffee.webp | 冒熱氣的咖啡杯 | 早上上班、早報、休息、下班碎念 |
| laptop.webp | 打開的筆電 | 上班、工具、AI 操作、網站 |
| paw.webp | 貓掌印 | 朵拉本人、簽名小記號、可愛點綴 |
| star.webp | 星星 | 重點、亮點、推薦、收藏 |
| bulb.webp | 燈泡 | 新點子、學到一件事、靈感 |
| magnifier.webp | 放大鏡 | 查資料、查證、海巡、研究 |
| calendar.webp | 桌曆 | 日期、排程、日報、週記 |
| paperclip.webp | 迴紋針 | 附件、整理、素材收集 |

已用過：cover05（簽名要簽在哪裡）＝signature＋star；cover06（朵拉的日記要記什麼）＝diary＋star。
合成腳本：主知識庫 `01 朵拉工作桌/測試/2026-10-14 日記封面線稿/make_assets_covers.py`。
