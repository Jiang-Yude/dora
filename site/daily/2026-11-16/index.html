Claude Code 官方文件整理：Auto mode 分類器與 Hooks

據 Claude Code 官方文件，Auto mode 讓工具呼叫經過分類器，分類器會阻擋不可逆、具破壞性或指向環境外部的操作。

預設情況下，分類器信任目前工作目錄與目前 repo 設定的 remotes。Claude 可推送到目前工作的 repo，包含 default branch；推送含 secret 的內容或向另一個 repo 開 pull request 會被阻擋。

文件稱分類器不讀取 repo 內 .claude/settings.json 與 .claude/settings.local.json 的 autoMode；必須強制阻擋的操作可在 managed settings 使用 permissions.deny，該規則在分類器之前生效且不能被覆蓋。

Hooks reference 將 hooks 定義為在 Claude Code 生命週期特定時點自動執行的 shell 命令、HTTP endpoint、MCP tool 呼叫、LLM prompt 或 subagent。PreToolUse 可在工具呼叫執行前阻擋該呼叫。

SpaceXSI 推出 Grok Bot，主打雲端電腦與跨工具作業

據 SpaceXSI 頁面，公司於 2026 年 8 月 11 日宣布推出 Grok Bot。頁面稱它是可在雲端使用自有電腦、跨工具與應用程式工作的 AI 助手，需要使用者核准時才回報。

頁面稱 Grok Bot 起初是 SpaceXSI 內部原型，曾被團隊用於銷售外聯、行銷活動、辦公室營運與修復錯誤。列出的團隊使用案例包括：銷售機器人研究客戶並準備個人化郵件草稿、示範環境機器人檢查環境與更新產品介面資料，以及管線營運機器人維護 CRM 和組織圖資料。

Grok Bot 處於 beta，提供給列出的 SuperGrok 與 Cursor 個人及團隊訂閱方案用戶使用，用量與 Grok、Cursor 方案分開計算，企業用戶可加入未來開放使用的候補名單。

另據 GitHub 個人頁，帳號 poteto（lauren）簡介為在 @xai-org 擔任軟體工程師，並屬於 @react compiler core team，置頂儲存庫包括 hiring-without-whiteboards、react、react.dev、react-native 與 cursor/plugins。

你的 AI 代理會挑可改造的那台：韌體開放與 AI 寫韌體

據 geoffstearns.com 上的文章，M-VAVE FM-1 是一款約 70 美元的口袋型 FM 合成器，機主從 9 月開始撰寫自訂韌體，作品包括虛擬類比合成器、多軌 groovebox、暗氛圍取樣器與 Doom 移植版。作者根據開發者在論壇的發文表示，這些韌體幾乎都是用 AI 程式編寫工具製作。

文章也舉了其他例子：Bambu Lab 以安全更新為由在印表機韌體加入伺服器授權，部分機主視為廠商鎖定；Google 要求開發者驗證身分才能在認證的 Android 裝置上安裝應用程式，自 9 月 30 日起在四個國家生效，並計畫於 2027 年全球實施。

OpenAI：Nathaniel Craig 與 GPT-6 Astra 提出標準模型格點定義

據 OpenAI 頁面（日期為 2026 年 11 月 15 日），Nathaniel Craig 介紹他與 GPT-6 Astra 合作提出粒子物理標準模型的候選格點定義。頁面稱 Craig 提出初始策略，GPT-6 Astra 協助將其發展為構造，並主導詳細證明。Craig 是加州大學聖塔芭芭拉分校粒子理論小組負責人，以 OpenAI 客座科學家身分發表首篇客座文章。

文章指出，標準模型描述已知基本粒子以及強力、弱力和電磁力，完整理論在連續時空中的非微擾定義仍未建立。弱作用對左右手費米子的作用不同，直接格點化可能產生額外的右手粒子，造成粒子內容不符。文章稱，重疊費米子可處理額外粒子問題，但完整標準模型仍需為費米子積分測度確定一致的相位。

據論文摘要，作者在四維歐幾里得格點上，為包含標準模型的一類非阿貝爾手徵規範理論構造了重疊費米子的規範不變測度。論文列出 Lean 形式化、二維類比構造檢查與另一種獨立方式構造的測度三種補充驗證，並指出這屬於原理上的構造，仍需研究實際數值界限、實用模擬與反射正性等。
