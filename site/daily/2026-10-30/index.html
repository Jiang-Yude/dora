1AI應用

Anthropic 說明 subagent 何時該開，Claude Code 文件列出內建類型

據 Anthropic 官方部落格與 Claude Code 文件，Subagent 是擁有自身上下文窗口、工具與指令，並由協調器編排的 agent，適用於驗證、平行工作與模組化權限控制。部落格指出，在數個企業部署比較中，具備技能的單一 agent 在品質上常勝過 subagent 設計，且每次任務的成本和延遲通常更低。

部落格列出三種適合使用 subagent 的情境：單一 agent 循環因上下文膨脹出現可測量的效能下降；需要以乾淨且用後即丟的上下文窗口平行處理多任務；單一 agent 難以選取合適工具，或系統提示詞出現衝突指令。

漸進式揭露讓 agent 先讀技能和工具的簡短描述，Anthropic 藉此為更進階模型減少 Claude Code 超過 80% 的系統提示詞長度。據文件，每個 subagent 在獨立上下文窗口運行，其請求會計入主對話的使用量限制。內建的 Explore 和 Plan subagent 為唯讀，禁止 Write 和 Edit 工具。

2AI產業趨勢

Anthropic 實驗 50 位分析師，86% 決策與 AI 被指定的立場一致

據 INSIDE 報導，Anthropic 對齊團隊在官方研究部落格發表一項隨機對照實驗，完整論文同步公開。實驗招募 50 位具因果推論經驗的專業分析師，使用 Claude Code 完成虛構的 Greenfields 農業合作社農業輔導計畫統計分析。研究團隊事先以擲硬幣方式隨機指定每位分析師的 AI Agent 在各項決策上的偏好立場，且未事先告知分析師。

4 項分析決策中，分析師的選擇有 86% 與 AI Agent 被指定的立場一致，高於意見完全不起作用時的預期比例 50%。實驗使用 Claude Opus 4.8，AI 的傾向寫在系統提示詞中，並要求在證據不利時改變立場，不得扭曲結果或隱藏資料。

任務後問卷顯示，77% 分析師至少在一題說明理由時重複了 AI 的論點，只有 15% 提到出處來自 AI Agent。另有 11 人自行選擇不使用 AI Agent，其中 6 人出現嚴重方法錯誤，使用 AI Agent 的 50 人中則有 3 人。

3AI工具發表

Google 推出 Connected Apps 平臺，第三方應用可串接 Gemini 與搜尋

據 iThome 報導，Google 推出 Connected Apps Platform 預覽版，讓第三方開發者透過 MCP 將自家服務功能提供給 Gemini 與 Google 搜尋使用。Gemini 與搜尋目前合計已推出超過 50 款 Connected Apps，Adobe、Experian、Localiza 及 Peloton 已在 Gemini 提供整合，預計未來幾周擴大至搜尋。

雲端 MCP 伺服器可讓服務提供給 Gemini、Google 搜尋或兩者，必須提供公開的 HTTPS 連線端點。Android MCP 透過 Android 的 AppFunctions API 開放應用程式原生功能，僅支援 Android 版 Gemini。

MCP 並非取代既有 API，第三方服務仍能透過原本的 API 處理查詢、訂購等後端操作。應用通過 Google 審查後才能正式發布。Google 尚未公布全面開放時間。

4AI工具發表

GitHub 發表 Copilot Fusion，單一任務內可跨模型協同

據 iThome 報導，微軟 GitHub 於 2026 年 10 月 29 日當周宣布推出 Copilot Fusion 協調系統。Copilot Fusion 能讓 AI 開發助手依推理、程式碼生成、除錯、工具使用等任務需求，自動選擇與協調不同模型。已上線提供給 Visual Studio Code、GitHub Copilot App、GitHub Copilot CLI 及 JetBrains IDE 的所有 Copilot 方案。

Copilot Fusion 整合 Project HydraFusion 的多模型協作與 Copilot 自動模型選擇器改進版本。Project HydraFusion 包含單一模型、逐級升級以及跨模型家族審查修正三種執行流程，並依任務自動選擇。

在 Artificial Analysis Coding Agent Index 測試中，Copilot Fusion Max 混合使用 Anthropic 和 OpenAI 獲得 60 分，比 Claude Opus 5.5 低 2 分，相較單獨使用後者可節省一半 API 成本與約 40% 的時間。

5AI模型

Google 發表 Gemini 4 Carbon，綜合能力評測登頂

據 iThome 報導，Google 於周三（10/28）發表新一代 AI 模型 Gemini 4 Carbon，這是繼 9 月底 Gemini 4 Argon 後推出的新一代前沿模型。Google 表示 Carbon 著重強化程式開發、代理式 AI、科學研究及長時間自主執行任務的能力，能持續數天處理複雜工程問題。

在第三方評測機構 Artificial Analysis 的綜合能力指數（Intelligence Index v5.0）中，Carbon 以 59 分登上排行榜首位。Google 公布的 17 項基準測試中，Carbon 在 15 項取得領先成績。

資安方面，Carbon 在 SEC-bench Pro 取得 88.2%，ExploitGym 為 54.8%，CWE-bench 為 71.0%。這 3 項測試皆在未啟用安全防護限制的情況下進行，成績未必能直接反映實際部署後的表現。Google 正參與美國政府自願性的模型上市前測試程序，本周起先透過 Fairwind Program 提供部分受信任資安防禦人員使用，尚未公布全面開放日期。
