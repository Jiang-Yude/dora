Google 發表 Gemini 4 Argon，開放 API 與訂閱版使用

Google DeepMind 資深副總裁 Koray Kavukcuoglu 於 2026 年 10 月 13 日發表 Gemini 4 Argon。據 Google 官方部落格，開發者與企業可透過 AI Studio 與 Gemini platform 的 API 使用，Google AI Ultra 與 Pro 訂閱者可在 Gemini 應用程式及搜尋的 AI Mode 使用。

文章稱 Argon 在衡量金融、程式編寫、法律與稅務表現的 Vals Index 排名第一。推出初期價格為每百萬輸入 token 2 美元、每百萬輸出 token 10 美元，快取輸入 token 折扣 95%。

Google 列出多項內部案例：Antigravity 中的代理程式碼提交量增加超過 35%，程式碼回復減少近三分之一；Chrome 團隊重構 Chromium 數百個檔案，把核心網頁處理與約六百萬行舊版瀏覽器功能資料夾分開；xTB 分子結構預測最多加速 2.3 倍，Gemma 4 E2B 端到端推論加速 2.85 倍。

原始資料來源：Gemini 4 Argon: Built to solve your hardest problems

SpaceX 推出 Grok Voice 3.0，用於星鏈客服

據 INSIDE 報導（原刊登於鉅亨網），SpaceX 於週三（14 日）推出語音模型 Grok Voice 3.0，並稱其為全球最聰明的語音到語音模型。SpaceX 表示該模型已部署於星鏈客服，可在無須人工介入下解決約 70% 的來電，系統每天處理約 2 萬通來電。報導指出，SpaceX 未揭露 70% 的統計期間、問題類型分布與判定標準。

第三方評測方面，Artificial Analysis 語音到語音綜合指數中 Grok Voice 3.0 得 86.9 分居冠。Speech Agent Arena 任務成功率 94.8% 排名第一，Tau Voice 得分 71.6% 排名第二，低於 GPT-Live-1 Astra 的 74.5%；使用者偏好 Elo 為 1070，排名第三。

Grok Voice 3.0 透過 Voice Agent API 及 Voice Agent Builder 開放，定價每分鐘 0.08 美元。報導也提到它支援特斯拉車內每天數百萬次對話。

原始資料來源：SpaceX 發布最強語音 AI 模型 Grok Voice 3.0 搞定七成星鏈客服來電 - INSIDE

Anthropic 自研版本控制系統 Scion，取代 Git 管理 monorepo

據 Anthropic 工程部落格，2026 年 5 月公司平均每天合併約 2,500 項程式碼變更，到 9 月每天超過 30,000 項。為支應成長，Anthropic 建立內部版本控制系統 Scion，並在五個月內把主單一程式碼庫從 Git 完整遷移；同期也推出程式碼審查介面 Antique、程式碼搜尋與來源控制 IAM 系統。

文章說明，主分支歷史接近 100 GB，壓縮後工作副本超過 25 GB，CI 每天約 2,500 萬次 checkout，若以天真方式抓取流量會超過每日 600 PB。Git 假設客戶端離線並持有完整儲存庫，Anthropic 的客戶端則多為持續連線的代理與自動化任務。

Scion 由伺服器處理檔案歷史、blame、提交、merge 與 rebase，客戶端只保留有界的本機物件快取。文章稱各層快取命中率超過 99%，所需 CPU 與記憶體比先前 Git 鏡像基礎設施少 200 倍，檢出速度從數分鐘縮短到數秒。Anthropic 也表示 Scion 不適合一般用途取代 Git，主要適用於極大型單一程式碼庫。

4AI工具發表

DeepSeek API 文件介紹 Search 與 Fetch 兩個網頁存取 API

據 DeepSeek API 文件，Search API 與 Fetch API 由 DeepSeek 自有搜尋引擎提供支援。Search API 依查詢尋找網頁並回傳結構化結果，Fetch API 擷取單一網頁並以 Markdown 回傳內容。兩者都是原始 JSON API，沿用 DeepSeek API 相同的 Bearer 認證，端點分別為 /v1/tools/search 與 /v1/tools/fetch。

Search 的 query 為必填，長度 1 至 128 個 Unicode 字元；count 預設 10，可設 1 至 50；need_content 預設為 false，此時 content 欄位為空字串。成功時回傳 HTTP 200 與 results 陣列。

Fetch 的 url 必填，最長 8192 個字元，須為含主機的 HTTP 或 HTTPS 網址，且不得含使用者名稱或密碼；擷取結果受目標網站可用性與存取政策影響。文件列出的錯誤碼包含 400、401、402、403、404，涵蓋無效請求、金鑰無效、餘額不足、安全政策拒絕與無法取得頁面。

論文提出 HybridAgents，讓代理在潛在空間推理與文字行動間切換

據 arXiv 頁面，論文《Hybrid Reasoning Agents》於 2026 年 10 月 13 日提交，編號 arXiv：2610.18861，全文 45 頁、含 12 張圖。

摘要提出 HybridAgents，讓代理在統一生成過程中，動態切換潛在空間推理與文字互動。HybridLink 負責文字模式與潛在模式之間的切換，連續工作記憶則保留跨多輪的混合上下文。訓練方面，HybridSFT 教導骨幹模型與 HybridLink 協調，以穩定整合工具的混合生成；HybridRL 學習何時在潛在空間思考、何時以文字行動。

研究團隊在 3 種模型規模與 11 個基準測試上評估，範圍包括數學、科學、醫學、搜尋與代理推理。摘要報告，相較於前沿 LLM 代理及文字式、潛在式代理框架，HybridAgent 效能提升 10.4%，token 減少 35.5% 至 54.7%，推論速度提高 1.8 至 2.6 倍，成本節省 2.7 至 3.7 倍。

原始資料來源：[2610.18861] Hybrid Reasoning Agents
