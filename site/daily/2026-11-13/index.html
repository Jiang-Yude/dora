Claude Code v2.1.323 新增實驗性 Code Mode

Anthropic 於 11 月 12 日在 GitHub 發布 Claude Code v2.1.323。這個版本新增實驗性、須選擇啟用的 Code Mode，讓 Claude 以 JavaScript 呼叫工具，發布說明提到組織可以關閉此功能。

外掛方面，plugin.json 新增 engines["claude-code"] 欄位。發布說明稱，超出所列 Claude Code 版本範圍的外掛不會安裝、更新或載入。claude plugin validate 也新增對外掛 TypeScript hooks 模組的型別檢查。

修正項目方面，發布說明列出：重複執行 /compact 時不再摘要掉 Claude 尚未回答的訊息，並有多項登入與工作階段問題獲得修正。權限方面，Bash 權限規則未涵蓋某些命令、Write 與 Edit 可寫入 Read deny 規則涵蓋路徑等問題也列入修正。

另外，permission-mode 設為 auto 或 defaultMode 設為 auto 時，若 auto mode 不可用，現在會以要求確認的 Manual mode 啟動。

2AI應用

AWS 推出完全由 AI 代理人開發的雲端模擬器 AWS Emulator

AWS 於 11 月 11 日宣布推出 AWS Emulator，供開發者在本機或 CI 環境測試使用 AWS API 的應用程式。據 iThome 報導，這個模擬器完全由數千個自主 AI 代理人開發，AWS 工程團隊沒有撰寫或審查任何一行產品程式碼。

AWS 官方文章描述，專案起初是週末實驗，Kiro 約 15 分鐘產生 Amazon SQS 初版，之後擴展到其他服務。代理人的工作包括建立並對真實 AWS 驗證測試、重播測試找出差異、修復問題，已建立數萬項 fidelity tests，修改須通過合併關卡。據 iThome 報導，AWS 工程師 Matthew Goldberg 表示專案受到 Anthropic 2 月以 16 個 Claude 代理人製作 C 編譯器的研究啟發。

AWS Emulator 以 Rust 實作，不收取額外服務費，原始碼公開於 GitHub，採 CC0 1.0 授權。尚未支援的操作會回傳 HTTP 501，資源狀態保存在記憶體中，停止後不保留。AWS 表示它不應用於正式工作負載或安全性測試，不會像 AWS 一樣評估 IAM 政策，每個模擬器僅代表單一帳號。

Google 發表 Gemini 4 Hydrogen，主打代理工作流程的速度與效率

Google 於 11 月 12 日發表 Gemini 4 Hydrogen。原文稱它面向日常程式開發與代理工作流程，著重速度與效率；Hydrogen 為多種代理工作流程的快速執行而設計。

提供範圍包括所有層級的 Google AI Studio、Gemini API、Gemini for business、Gemini app、Google 搜尋，以及 Google Antigravity 的付費 Google AI Pro 和 Ultra 訂閱者。Hydrogen 具備 100 萬 token 的上下文視窗，每百萬輸入 token 收費 1.50 美元，每百萬輸出 token 收費 7.50 美元。

Google 稱，Hydrogen 在 Artificial Analysis Intelligence Index 預設 high 設定下得 51 分，高於 Argon 的 50 分。相較 Gemini 3.8 Flash，預設 high 設定下完成任務速度快 2.5 倍，Terminal-Bench 4.1 得分由 18.2% 提升至 57%，捏造資訊減少超過 5 倍。

4AI產業趨勢

史丹佛研究：AI 暴露職業中，年輕勞工就業人數較低

史丹佛數位經濟實驗室的論文使用 ADP 行政薪資資料，涵蓋數百萬名美國勞工，資料截至 2026 年 6 月。作者表示，資料中沒有顯示 AI 造成普遍、全經濟範圍的工作流失。在 AI 暴露程度較高的職業中，22 至 25 歲勞工的就業人數，比照較低暴露職業的增幅推算低了 19%，有經驗的勞工沒有同等差距。

作者指出，年輕勞工的差距主要與招聘減少有關，差距自 2025 年 8 月首次記錄後持續擴大。就業下降集中在 AI 主要替代人工作業的職業；AI 主要輔助勞工的職業，就業持平或上升，尤其是有經驗的勞工。調整主要表現在就業人數上，研究呈現的是描述性結果，並未估計 AI 的因果影響。

另一篇 NBER 論文 Generative AI at Work 研究 5,179 名客服人員分階段使用生成式 AI 對話助理的情況，使用後每小時解決的問題數平均增加 14%。對新手及低技能員工的生產力提升為 34%，對有經驗及高技能員工的影響很小。論文也報告顧客評價改善、員工留任增加。

ChatGPT 開放商家認領檔案，美國電商可先上架 Business Agent

OpenAI 於 11 月 10 日推出 Businesses in ChatGPT 測試版，商家可透過 Business Hub 認領商家檔案、管理資訊並查看互動彙整數據。認領須通過審核，並完成 Persona 身分驗證後才能發布資訊變更或建立 Agent。

Business Hub 的 Insights 顯示過去 28 天的提及次數與網站點擊。線上商家的網站被 ChatGPT 引用才計為一次提及，僅出現品牌名稱不算。OpenAI 表示不會向商家提供使用者對話或 Business Agent 聊天紀錄。

Business Agent 供符合資格的美國電商與線上服務業者建立、測試及發布，目前可解說商品與政策並連結商家網站，購買、預約或查詢訂單須到商家網站處理，不使用 Shopify 也可建立。據 Digiday 報導，OpenAI 商業化副總裁 Benji Shomair 表示 Business Hub 與 Agent 目前免費，未排除未來採付費模式。OpenAI 也可讓商家贊助 Agent，作為 ChatGPT 廣告的導流目的地。
