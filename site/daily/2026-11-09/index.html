1AI工具發表

DeepSeek 在 GitHub 公開 dsh-superagent 研究原型

DeepSeek 在 GitHub 公開 dsh-superagent-prototype 專案，採 MIT 授權開源。據專案 README，它是僅供參考的研究原型，並非 DeepSeek 官方產品。

README 描述它是供單一 GitHub 儲存庫使用的主動式程式碼代理，會監聽 GitHub。獲准的使用者提出工作後，代理會建立工作項目，並回到原對話回覆，例如提供 pull request。

DeepSeek API 定價頁以每 100 萬 token 列價。deepseek-flash 快取未命中的輸入價離峰 0.15 美元、尖峰 0.3 美元，輸出離峰 0.6 美元、尖峰 1.2 美元；deepseek-v4-pro 輸入離峰 0.66 美元、尖峰 1.32 美元，輸出離峰 1.98 美元、尖峰 3.96 美元。尖峰為週一至週五 UTC 01:00 至 04:00 與 06:00 至 10:00，不含中國公眾假期。

2AI產業趨勢

高盛限縮 Claude Code 使用對象，僅工程師可用

據 State of AI 報導，高盛於 10 月更新內部指引，將 Anthropic 的 Claude Code 與微軟的 GitHub 使用權限限縮給工程師。負責交易、量化研究與軟體工程交界工作的 Strats 人員仍可使用。高盛發言人 Nick Carcaterra 表示，銀行向員工提供特定 AI 工具，是為了判斷這些工具在公司內的最佳用途。報導引述知情人士稱，部分交易員對限制感到不滿。

高盛資訊長 Marco Argenti 在 7 月曾談到，非技術員工用 AI 建立工具，再交給工程師改進。據 The Next Web 報導，Argenti 在 10 月 9 日表示，高盛約 47,000 名員工中有超過 12,000 名開發者。

據 Reuters 在 4 月的報導，一名知情人士表示，高盛香港員工近幾週已無法透過內部 AI 平台使用 Claude，Gemini 與 ChatGPT 仍可使用。另據 SEC 文件，Anthropic 於 10 月 26 日提交 S-1，申請在那斯達克以代號 ANT 上市，高盛與摩根士丹利列為承銷代表。

3AI模型

llama-modchip 讓 284B 的 DeepSeek-V4-Flash 在 64GB RAM、無 GPU 下執行

GitHub 專案 llama-modchip 是一組 ggml 與 llama.cpp 的核心補丁、量化轉換工具及執行工具，目標是在 CPU 的系統記憶體中執行稀疏 MoE 模型。據 README，DeepSeek-V4-Flash 有 284.33B 總參數、13.17B 啟用參數。

README 稱專案的 DeepSeek-V4-Flash GGUF 檔為 56.56 GiB、1.71 bpw。在 64GB RAM、無 GPU 的配置下，模型於 256K context 的 VmRSS 約為 57.61 至 58.9 GiB，可不使用 swap。預設每層執行 6 個 routed experts，不裁減 experts。

效能數據為頁面自述，測試平台為 Ryzen 9 9955HX、16 核心、無 GPU：prefill 約 43.16 至 44.36 tok/s，Top-6 lossless decode 約 9.06 至 9.95 tok/s。

4AI應用

作者分享以 Git 看板管理多個 AI 代理任務的做法

據作者 Sergey Kuhne 的部落格文章，使用 Claude Code 或 Codex 終端工作時，常因等待回覆而開啟其他任務，之後在多個對話串之間切換，直到難以掌握各自的上下文。他把主要問題歸納為任務排序與上下文管理。

他把工作佇列放在 Git：每個任務是與相關程式碼同一個 repo 的 Markdown 檔，看板狀態以已提交的快照保存。代理會循環處理看板，研究新任務、建置人類標記為可安全建置的任務、執行測試與瀏覽器檢查，並驗證已部署的項目。涉及敏感程式碼的工作會在分支上建置並先詢問，代理不會部署到正式環境，由作者負責部署。

需要本人判斷的事項集中在 owner inbox，由腳本整理出優先清單。閱讀介面是每個循環從 Git 重建的 Claude artifact，作者說它只供檢視，Git 才是紀錄。作者一次選一個項目、載入上下文、作出決定，再放回佇列。他表示這套方式仍然令人疲累，但不再覺得分心或迷失。

5AI產業趨勢

據報 Apple 執行長要求加快 Siri 朝 agent 發展

據 The Verge 報導，Bloomberg 的 Mark Gurman 表示，Apple 執行長 John Ternus 正向 AI 負責人 Craig Federighi 施壓，要求加快 Siri 路線圖，打造能與 OpenAI 的 Dots 或 Meta 的 Muse 競爭的 AI agent。文章稱，Federighi 已在很短時間內交付可運作的 Siri AI 版本。

文章預期 Siri 在未來幾個月有兩項重要改進。第一項是更細緻地控制 Apple 自家 app，預計隨 iOS 27.3 推出。另一項是整合第三方 app，預計在春季推出，例如透過 Grubhub 下單或透過 OpenTable 預訂餐廳。

文章稱，Apple 預期讓 Siri 更具 agent 特性，能執行持續進行的任務，不只處理一次性指令。Gurman 說，Dots、Muse 和 Grok 能追蹤目標、判斷下一步並持續推進。文章作者表示，Apple 最早可能在明年讓 Siri 轉向這類 agent 形態。
