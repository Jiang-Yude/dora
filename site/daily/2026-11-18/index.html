1AI應用

Matt Pocock 提出 Home Repo 模式，用單一儲存庫統管多個 repo 的 AI agent

據 aihero.dev 文章，作者 Matt Pocock 介紹 Home Repo 模式：用一個 Git 儲存庫存放技能（skills）、AGENTS.md 與共用文件，使用者在其中啟動 AI agent，agent 依 AGENTS.md 的導覽指標，視需要開啟或 clone 其他儲存庫。

文章指出，專案跨多個 repo 時，從單一 repo 啟動的 agent 只能看到該 repo，技能與設定可能各自複製，跨 repo 規劃功能也缺少全貌。

文章附上可貼給 coding agent 的設定提示詞，流程為四步：盤點家目錄下的 Git repo；將技能與文件分成 shared、duplicate、repo-specific、installed 四類；列出計畫，核准前只讀不改且不讀 .env 等機密檔；最後建立 Home Repo 並提交。

規模上，文章稱約 20 個 repo 可運作，約 400 個時逐 repo 指標會讓 agent 決策過多，需採漸進式揭露。

2AI應用

Anthropic 刪除 Claude Code 超過八成 system prompt，並公開 Opus 5.5 使用建議

據 claude.dev 部落格文章，Anthropic 為 Claude Opus 5 與 Claude Fable 5 等模型，移除了 Claude Code 超過 80% 的 system prompt，並稱在 coding 評測中沒有可測量的損失。文章由 Thariq Shihipar 撰寫，頁面標示發布於 2026 年 7 月 24 日。

文章稱，system prompt、skills、CLAUDE.md 與使用者要求可能互相衝突，團隊因此刪除部分原有約束，讓模型依脈絡判斷。做法轉變包括：由明列規則改為讓模型判斷、由提供工具範例改為設計工具介面、由一次放入所有資訊改為按需載入。

另一篇由 Addy Osmani 撰寫、標示發布於 2026 年 9 月 22 日的文章談 Opus 5.5。文章稱 Opus 5.5 每次回覆前都會思考，在其聊天產品測試中，移除「think carefully」指示後回覆開始得更快，品質沒有明顯下降。

3AI模型

OpenAI 發表 GPT-6.2 Astra 與 GPT-6.2 Sol 兩款新模型

OpenAI 發表兩款新模型：定位為處理最困難專案的前沿模型 GPT-6.2 Astra，以及定位為日常工作的高效率多用途模型 GPT-6.2 Sol。

據 OpenAI 頁面，在 Agents' Last Exam 上，GPT-6.2 Astra 比 GPT-6 Astra 高 5.2 分、成本不到三分之一，比 Claude Fable 5.2 高 5.5 分，成本為其 5%；頁面註明 Fable 5.2 的結果排除了使用 fallback 模型的九項任務。

價格方面，GPT-6.2 Astra 的 API 每百萬 token 為輸入 8 美元、快取輸入 0.40 美元、輸出 40 美元，輸入與輸出價格比 GPT-6 Astra 低 20%。GPT-6.2 Sol 沿用 GPT-6.1 Sol 的 API 價格。

OpenAI 表示兩款模型自發布當日起提供給 ChatGPT Work 與 Codex 的 Plus、Pro、Enterprise、Edu 使用者，開發者可透過 API 使用。

原始資料來源：Introducing GPT-6.2 Astra and Sol | OpenAI
4AI工具發表

Google 將 Spark AI agent 更名為 Tasks 並開放免費使用

據 The Verge 報導，Google 將 Spark AI agent 更名為「Tasks」並開放免費使用。報導稱 Tasks 由 Google 的 Gemini 4 Hydrogen 模型驅動，可建立餐點計畫、管理行事曆，並搜尋電子郵件以找出可能不再需要的定期支出。

報導稱，Google 於同年 5 月首次介紹 Spark，當時僅提供給 Google AI Pro 與 Ultra 訂閱者。現在 Tasks in Gemini 開放給美國、加拿大、日本、韓國、澳洲及印度的所有使用者，使用者可在 Gemini 首頁將「Chat」切換為「Tasks」。

報導稱，美國使用者還可讓 Tasks 致電商家比較商品價格與查詢庫存、使用 Google Pay 購買商品，也可透過寄電子郵件至 gemini@google.com 或傳簡訊指派任務。

報導轉述 Google 表示，Gemini 會在專屬於使用者帳戶、不與其他使用者共用的硬體隔離虛擬機器中執行任務。

原始資料來源：Google’s Spark AI agent becomes ‘Tasks’ — and now it’s free
5AI產業趨勢

哈佛研究：導入 AI 程式碼代理後，瓶頸移到程式碼審查

據 ComplexDiscovery 報導，哈佛大學的 Fiona Chen 與 James Stratton 在工作論文中研究 AI coding agents 的影響，樣本涵蓋 718 家公司、725,938 名員工，期間為 2021 年 1 月至 2026 年 3 月，資料來自 Jellyfish 工程活動資料與 Revelio Labs 的 LinkedIn 就業紀錄。

報導稱，導入 AI agents 後，每人每月新增程式碼增加 1,494 行（基準 5,017 行，約 30%），但以部署到正式環境的 Jira issues 衡量，每人每月僅增加 0.12 個（基準 3.67，標準誤 0.17），統計上與零無法區分。

審查端方面，pull request 從提交到合併的時間增加 3.45 天（基準 7.03 天，約 49%），收到正式修改要求的比例從 13% 增加約 12 個百分點，每個 pull request 的審查留言增加 35%。
