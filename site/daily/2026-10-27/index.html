1AI應用

Anthropic 建議企業減少使用子代理，單一代理加技能常比多代理架構表現更好

據 INSIDE 報導，Anthropic 於 10 月 22 日發布文章，建議企業打造 AI 代理時，把部分專家子代理併回主代理循環。Anthropic 表示，在其比較的數個企業部署案例中，單一代理搭配技能的設計，品質常勝過單一大提示與子代理設計，每項任務的成本與延遲通常也較低。

文章列出多代理架構的五個常見問題：代理間交接時遺失細節、子代理數量膨脹、系統提示規則互相衝突、評測只侷限於各自的子任務，以及延遲增加。文章舉例，一家公司的面向客戶代理有十多個專家子代理，使維持一致的品牌體驗變得困難。另有一位客戶比較多代理框架與單一代理循環後，表示後者速度約快兩倍。

文章認為子代理仍適用於三種情況：單一代理因上下文膨脹出現可量測的效能下降、多項任務需在獨立新上下文中平行處理，以及單一代理難以選工具或提示存在衝突指令。遷移上，文章建議先建立評測集，10 個標準範例即可起步，每次將一個子代理折入為技能與工具並比較評測，只有折入後分數較差才保留該子代理。

2AI工具發表

1Password for Agents 推出，AI agent 登入網站時不經手用戶密碼

1Password 於 10 月 22 日宣布推出 1Password for Agents，讓個人 AI agent 在不接收也不看見密碼、秘密或憑證的情況下，使用經核准的登入資料完成任務。agent 抵達登入表單時，會以唯一數位金鑰向 1Password 驗證身分；用戶可在自己的裝置上查看所需憑證及用途並決定是否核准，核准後由 1Password 直接填入。

據 INSIDE 報導，用戶能檢視將分享的內容，逐次核准每次登入，並可隨時中斷整合。密碼變更時，只需在保管庫更新一次，已連結的 agent 即會沿用最新登入資料。

合作名單方面，1Password 公告列出 Meta 的 Muse、Anthropic 的 Claude、OpenAI、SpaceXSI 的 Grok Bot 與 Town 的 Townie。1Password.com 的 Individual 與 Family 帳號可免費使用，1Password.eu 與 1Password.ca 帳號目前不支援。

3AI工具發表

Hob 開源本機 AI 工具，定位為 Claude 與 ChatGPT 的替代方案

Hob 是一款可在自己電腦上使用的 AI 工具，專案頁面副標稱它是在自己的電腦上使用 AI 的較簡單方式。Hob 自述為免費、開源，定位為 Claude 與 ChatGPT 的替代方案，標示由 Frigade 製作。這則消息出自 Show HN 的發表，專案放在 GitHub 的 FrigadeHQ/hob 儲存庫。

據專案頁面，Hob 在 Mac、Windows 和 Linux 上於本機執行開放權重模型，例如 Gemma 和 gpt-oss，頁面稱其私密，也可離線使用。README 提到 Hob 會挑選適合該電腦的開放權重模型，並協助完成設定，可用於填寫 PDF、處理文件等工作。

支援平台方面，README 列出 Apple silicon Mac、Windows 和 Linux，記憶體需求為 8 GB 或以上。專案官方網站為 hob.chat，提供 Mac、Windows 與 Linux 的下載版本。GitHub 頁面將此儲存庫標示為 Public，授權條款為 MIT license。該儲存庫當時累積 190 次提交、88 顆星星、2 次 Fork。

原始資料來源：GitHub - FrigadeHQ/hob: An easier way to use AI on your own computer. A free, open-source alternative to Claude and ChatGPT that runs open-weight models like Gemma and gpt-oss locally on Mac, Windows and Linux. Private, and works offline.
4AI產業趨勢

OpenAI 發布 Signals 資料，呈現近 100 個國家如何用 ChatGPT 工作

OpenAI 經濟研究團隊發布 OpenAI Signals 資料，呈現近 100 個國家的消費者如何將 ChatGPT 用於工作，涵蓋 165 種稱為 Intermediate Work Activities（IWAs）的工作活動，例如準備教學教材、開發行銷內容、撰寫程式與分析商業數據。資料以季度呈現，涵蓋 2025 年第一季至 2026 年第三季，並以 O*NET 作為整理跨職業工作活動類別的框架。

文章指出，在每季都有觀測資料的 74 個國家中，各國分類工作訊息裡最常見的十種活動平均占比，從 2025 年第一季的 56.0% 降至 2026 年第三季的 51.1%。文章表示工作相關使用逐漸不再集中於最常見的活動。另稱，在已映射美國職業的加權任務組合中，約 43% 落在個別未列出的「Other IWAs」，例子包括搬運材料、操作車輛及維護健康或醫療紀錄。

資料涵蓋個人 ChatGPT 方案的工作相關訊息，不含企業訊息或 Codex 使用。研究者不閱讀個別對話，由自動系統在移除識別資訊後分類，發布的是彙總統計，並對小群體結果採取保留措施及加入統計雜訊。

原始資料來源：ChatGPT’s expanding world of work | OpenAIData methodology | OpenAISpec: OpenAI Signals
5AI模型

OpenAI 推出 GPT-6.1 Terra，標準 API 價格比 GPT-5.6 Terra 低 50%

OpenAI 推出 GPT-6.1 Terra，結合視覺推理、電腦操作能力與更清晰自然的寫作。OpenAI 稱其標準 API 價格比 GPT-5.6 Terra 和 GPT-6.1 Sol 低 50%。GPT-6.1 Terra 提供給 ChatGPT Work 和 Codex 的 Plus、Pro、Enterprise、Edu 使用者。標準價格為每百萬輸入 token 1 美元、快取輸入 token 0.05 美元、輸出 token 5 美元。

Agents' Last Exam 以中等推理強度測試，GPT-6.1 Terra 比 GPT-5.6 Terra 高 15 個百分點，成本約為三分之一，每 token 價格約為 GPT-6 Astra 的十分之一，表現相當。在 Terminal-Bench 4.0 最高推理強度下，GPT-6.1 Terra 解出 50.3% 的任務，GPT-5.6 Terra 已公布的分數為 21.5%。
