1AI模型

微軟公布尖端模型MAI-Base-2，宣稱算力耗用僅競爭模型的1/4

據 iThome 報導，微軟公布自行開發的尖端模型 MAI-Base-2，並宣稱在多項核心效能與基準測試上超越 OpenAI 的主流模型，推論與訓練所耗算力只需對手的 1/4。微軟 6 月曾公布第一款自有模型 MAI-Base-1，以及以此為基礎的推理模型 MAI-Thinking-1。

MAI-Base-2 為混合專家（MoE）基礎模型，總參數量達 2.8 兆，推論時啟動 800 億參數。訓練在 1.6 萬顆 GB200 GPU 上歷時 38 天完成，訓練資料規模達 50 兆個 token。

微軟指出，在自有的程式碼撰寫、問答、數理科學問題等評估測試中，MAI-Base-2 超越 Kimi K3 等開放權重模型。微軟也宣稱，預訓練的浮點運算量比開源模型 DeepSeek-V4-Pro-Base 節省 4 到 12 倍，比 MAI-Base-1 節省 6.3 到 12.7 倍。

MAI-Base-2 處於後訓練階段，完成後會先整合至微軟產品，後續透過市集平臺 Foundry 提供給客戶。

2AI應用

CERN 與 Mistral 簽署意向聲明，攜手開發物理基礎模型

歐洲核子研究組織 CERN 與法國 AI 公司 Mistral 簽署意向聲明，計畫建立長期策略夥伴關係，開發用於科學發現的基礎模型。合作初期聚焦高能物理，雙方將結合 CERN 在基礎物理、科學資料與大型運算的專長，以及 Mistral 在大型模型訓練的能力。

合作目標之一，是開發單一預訓練的 Large Physics Model，原文稱這會是首個用於對撞機物理的基礎模型。模型預計以大型強子對撞機（LHC）數十億次模擬質子對撞資料訓練，設計用於重建粒子對撞、辨識粒子、標記意外訊號，以及評估未來的探測器設計。

原文說明，目前 LHC 的對撞重建依賴一連串專門演算法，逐步把探測器訊號轉換成物理分析使用的粒子與物件，基礎模型有望沿整個重建流程學習，並以單一模型支援多項任務。CERN 已儲存約 1 exabyte（100 萬 terabytes）的 LHC 實驗資料，高亮度 LHC（HL-LHC）預計約 2030 年開始運作，對撞次數將增加十倍。

3AI產業趨勢

傳 Accenture 將員工的 Claude 補助額度降為每月 29 美元

據 iThome 引述 404 Media 報導，IT 委外服務業者 Accenture 自 2026 年 10 月 1 日起調整 Claude Enterprise 的費用分攤政策，中央統一補助額度降至每人每月 29 美元。超出 29 美元的部分，須由特定專案或團隊經費補足差額。

政策調整前，部分大用量員工每月使用 Claude 的實際費用達 500 至 1,000 美元，包括開發內部工具或客戶專案的工程師。報導稱，部分員工反映新政策直接影響專案進行，也有用量超額的員工被暫停 Claude 存取權限。

Claude Enterprise 提供標準與 Premium 兩種收費層級，基礎月費分別為 25 美元與 125 美元，另依 token 用量計費。Accenture 多數員工配置為標準層級，公司文件顯示其全球員工數為 81.4 萬人。

iThome 另提到，Meta 將使用 Claude Code 的人數由約 6 萬人縮減至 3 萬人。

4AI模型

Meta、蘋果合作，讓 Muse Spark Open 在 Mac 上執行

據 iThome 報導，Meta 上週推出 Mac 版 Muse App 並上架 App Store，同時開放多模態模型 Muse Spark Open 的權重。Meta 執行長 Mark Zuckerberg 在 X 宣布，透過與蘋果及新任執行長 John Ternus 的合作，Muse Spark Open 可在 Mac Studio 上執行，Ternus 也回應了這項合作。

Muse Spark Open 是開放權重多模態模型，總參數量 8160 億，執行時啟動 420 億參數，脈絡空間為 100 萬 token，主要面向程式開發與 AI 代理任務。據報導，它能進行多步驟推理與規畫、呼叫工具、撰寫與除錯程式，並在長時間工作流程中診斷錯誤與重試，也能解讀截圖、圖表、文件、圖像和影音。

Meta 建議將模型整合至具有其他防護機制的 AI 系統，特殊應用情境則搭配額外安全護欄。模型可透過第三方推論平臺以 API 形式使用，權重可從 Hugging Face 下載，可部署平臺包括 Google Cloud、AWS 與 Microsoft 等。

5AI工具發表

Cursor 的 pstack 技能集，內建 23 個 playbook

Cursor 的 GitHub plugins 倉庫收錄名為 pstack 的技能集。依 README 自述，作者 poteto 曾在 Meta、Netflix 與 Cursor 工作，是 React 核心團隊成員，協助建立與維護 React Compiler。pstack 是他在 Cursor 日常使用的技能，目標是寫更少但品質更高的程式碼，並支援多個 agent 平行工作。

入口是 /poteto-mode，會依任務從 23 個內建 playbook 挑選流程，必要時呼叫其他技能。劇本涵蓋調查、修 bug、效能改善、功能開發、重構、PR 維護與合併、autonomous run、工作階段接手等用途。

pstack 可搭配不同模型，預設配置把程式碼委派交給 Grok，最困難的變更、文字與判斷交給 Opus 5.5。可在 Cursor 與 Claude Code 安裝，授權為 MIT。
