1AI工具發表

Anthropic 推出 Claude Ship，由 AI Agent 審查、修正並依政策核准 PR

據 INSIDE 報導，Anthropic 於 11 月 23 日推出 Claude Ship，由 Code Review、PR Steward、Claude Approvals 三個 AI Agent 組成，接手 GitHub PR 的審查、修正與核准，適用於 Claude Team 與 Enterprise 方案。

Code Review 已正式提供，有 Quick、Standard、Deep 三種審查等級，會對問題做對抗式驗證並分類後貼回 PR。PR Steward 與 Claude Approvals 處於 Beta：前者處理失敗的 CI 檢查與合併衝突，設計上不會核准或合併 PR；後者依儲存庫內的核准政策，可核准例行變更，也可要求人工簽核。

Anthropic 表示，Claude Code 團隊 6 月到 9 月合併的 PR 數量增加一倍以上，被還原的比例同期下降逾 40%。各 Agent 依 token 用量計費，啟用零資料保留或 HIPAA 設定的組織目前無法使用。

2AI應用

GPT-6.2 Astra 協助辨識耶魯館藏 1808 年匿名素描本作者

據 Simon Willison 部落格轉述，歷史學教授 Mark Humphries 分享了以 GPT-6.2 Astra 做歷史研究的案例。他讓模型查看耶魯大學 Beinecke Library 收藏的匿名 1808 年素描本，模型約 22 分鐘後提出作者可能是夏博子爵（vicomte de Chabot）。

Humphries 表示，Astra 建議查找 Chabot 的旅行日記來驗證假說。他取得日記後，認為筆跡與素描本相符，行程也與有日期的圖畫相合。他引述日記稱，1808 年 6 月 18 日抵達 Fort St. Joseph 後寫下自己「畫了一張素描」，並描述了與素描本相符的堡壘景象。

據耶魯館藏目錄，該素描本約 1808 年創作，作者未署名且身分不明，全冊已數位化。Humphries 也說，Chabot 的 Upper Country 日記約 162 頁，內容涉及毛皮貿易生活。OpenAI 的公告介紹了 GPT-6.2 Astra 與 Sol 兩款模型。

3AI產業趨勢

微軟 Agent 365 登錄 Agent 逾 5,000 萬，Copilot 擴大按用量計費

微軟在 2027 會計年度第一季財報會議上表示，Agent 365 登錄的 Agent 超過 5,000 萬個，較上一季增加逾 30%。客戶透過 Microsoft Purview 稽核的 Agent 活動累計超過 76 億次，較上一季增加 5 倍。

Satya Nadella 表示，微軟商業模式正從按席次訂閱擴大納入用量計費，透過用量計費實際消耗 Copilot credits 的客戶單季增加逾 75%。擁有超過 5 萬個 Copilot 席次的客戶數年增逾 8 倍。微軟也宣布 Agent 365 Business Analytics，用來檢視 AI 支出及其產生的價值。

據微軟說明，Business Analytics 可整合微軟與非微軟 AI 服務的成本與成果，並提供支出預測與情境規劃。財報新聞稿列出，9 月止季度 Agents and Infra 部門營收為 767.95 億美元，年增 25%。

4AI產業趨勢

作者談 LLM Agent 受提供公司限制：Bandcamp 與 YouTube 的差別

據 Michael Harley 在個人部落格的文章，他用 Claude Code 建立了一個技能：開啟 Instagram Reels，辨識其中的歌曲與演出者，再查找演出者的 Bandcamp 頁面，找到時提供網址讓他自行購買。

他表示，這個技能最近停止正常運作。他發現 Bandcamp 的搜尋 API 頁面新增了 challenge，而 Claude 表示不會協助他繞過。該技能的另一個分支會在 YouTube 尋找同一首歌，並可在他要求時下載到電腦上。作者指出，付費 AI 模型拒絕協助處理 Bandcamp 的驗證，卻願意協助下載未向樂團付費的歌曲。

他認為這顯示模型的行為受提供公司的允許範圍影響，也擔心模型的答案未來可能受產品置入影響。他說自己把 AI 視為工具，想在家用伺服器上執行本地模型，並在註腳澄清，自己是在回應 Claude 預先表示不會協助此事。

5AI模型

OpenAI 發表 GPT‑6 蛋白質設計能力研究

OpenAI 於 2026 年 11 月 24 日介紹一篇蛋白質生物學預印本。OpenAI 稱，GPT‑6 系列模型可透過推理和一般用途程式工具，設計新的蛋白質結構與序列，設計時不呼叫專門的生物學模型，研究者能用提示指定蛋白質要附著的位置與形狀。

OpenAI 與研究夥伴 Onava 進行實驗室測試。第一項實驗測試 322 種迷你結合蛋白與五種目標，35 種（10.9%）結合測試呈陽性。GPT‑6.2 先設計三維形狀，序列由專門模型 SolubleMPNN 提供。另有 182 種小型抗體重新設計序列，128 種（70%）顯示結合跡象。

由胺基酸序列預測三維結構的平均 TM-score，GPT‑6.2 為 0.26、內部最新模型為 0.38，專門模型 ESMFold2 為 0.93。篩選使用 Boltz-2、OpenDDE、ESMFold2 等專門模型，結果尚未證明模型能完全不依靠專門模型，端到端生成迷你結合蛋白。頁面指出，結合之外仍需評估專一性、穩定性與生物活性。
