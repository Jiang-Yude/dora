DeepSeek 在 GitHub 公開 dsh-superagent 研究原型

DeepSeek 在 GitHub 公開 dsh-superagent-prototype，是針對單一 GitHub 儲存庫的主動式編碼 Agent。據 README 說明，這是供參考的研究原型，不是 DeepSeek 官方產品，專案採 MIT 授權。

它會監聽 GitHub，也可選擇監聽飛書。獲得授權的人指派工作後，它會建立工單項目，在專屬的 Agent session 與目錄中執行，再回到原對話回覆，例如發送 Pull Request。

架構文件指出，Engine 是 Triggers、Threads、Decisions、Tickets 和 Assignments 的唯一寫入者。據 Thread Navigator 頁面（標示為機器翻譯），文章的合成實驗中，工作由只消耗時間的工具模擬，Super-agent 任務完成時間 p50/p95 為 12.4/15.7 分鐘，單一 session 中性提示組為 20.4/29.5 分鐘，頁面稱結果僅供參考。

2AI應用

微軟展示用 NuGet 套件封裝 Agent Skills

微軟 .NET 團隊公布實驗成果，展示將 Agent Skills 封裝進 NuGet 套件，讓函式庫開發者發布新版本時，可一併提供對應的使用指引。Agent Skills 以 SKILL.md 檔案記載適用情境、執行步驟及相關知識。據 iThome 報導，這類技能過去主要透過 Git 儲存庫或技能市集散布。

執行 dotnet restore 時，NuGet 會下載相依套件，封裝其中的 SKILL.md 也會出現在本機。微軟以 Markout 套件示範，內含五個技能，涵蓋內建形狀、組合內容與輸出格式等。配套工具 dotnet-inspect 可列出技能並輸出內容，dotnet-package-skills 則會掃描直接相依套件，將技能複製到 .agents/skills 目錄。

據報導，技能不會隨套件自動啟用，代理仍須自行找到並讀取檔案。微軟測試發現，前沿模型加入技能後改善有限，較弱模型則表現較差且不穩定。技能也可能增加詞元消耗。微軟同時提醒，代理讀取並遵循套件中的 Markdown 指引會帶來新的威脅途徑，並表示 NuGet MCP 尚未支援技能，計畫後續處理。

3AI產業趨勢

美國學校限制生成式 AI，Google 推引導式學習

Google 於 2026 年 11 月 3 日宣布，將 Guided Learning 引導式學習功能帶入 Google 搜尋與 Google Classroom。Classroom 版本自公告日起在全球推出，搜尋版本預計 11 月稍晚先在美國部分學校試辦，未來幾個月再逐步擴大。

據 iThome 報導，紐約市在 2026 年 9 月 2 日宣布，2026 至 2027 學年對學前教育至 8 年級學生實施為期一年的生成式 AI 禁用措施，影響近 60 萬名公立學校學生；高中生僅能在教師監督下試用經審查的工具。

Google 表示，K-12 學生帳號的 Gemini、Gemini Notebook、Gemini in Classroom 與 Google 搜尋 4 項服務將預設關閉，須由學校管理員啟用。Google 公布與東京大學合作、逾 300 名學生參與的隨機對照試驗，使用一般網路工具的學生成績提高 5.3 個百分點，可使用 Guided Learning 的學生提高 8.1 個百分點。

Moonshot AI 公開 Kimi K3.1 Pro 模型權重

Moonshot AI 在 Hugging Face 公開 Kimi K3.1 Pro 的模型權重。模型卡稱它是開放權重、原生多模態的代理模型，為 Moonshot AI 迄今最強的 3T 級模型，也是 K3.1 系列首款模型。

規格方面，模型採 Mixture-of-Experts 架構，總參數量 2.8T，啟用參數量 104B，上下文長度為 1,048,576 tokens，支援文字與圖片。視覺編碼器為 MoonViT-V2，參數量 401M，並採 MXFP4 權重與 MXFP8 activations 的量化感知訓練。

評測設定上，除非另有註明，結果使用 reasoning effort max、temperature 1.0、top-p 0.95。模型卡列出 Terminal-Bench 4.0 為 65.7、SWE Marathon v1.1 為 51.7、BrowseComp 為 92.1、GPQA-Diamond 為 94.2、MMMU-Pro 為 84.1。

開源 CLI 工具 Gauge，改善 coding agent 使用文件的體驗

Gauge 是開源命令列工具，用來評估並改善 Skills、CLIs、SDKs、MCPs 與文件被 coding agent 發現及使用的體驗，專案採 MIT 授權。據 README 說明，它讓真實代理執行任務、記錄受阻之處，並讓開發者自己的 coding agent 在發布前測試修正。本機完整流程使用 Docker，不要求 Gauge 帳號。

README 列出的常見問題包括互動式命令阻塞代理、代理使用過時命令或 API 模式、該用的 Skill 未被使用，以及代理無法理解跨多個命令的工作流程。支援的代理有 Claude Code、Codex、Pi 與 OpenCode，事件會被整理成一致的逐字紀錄。

安裝需要 Node.js 22.13 以上、npm、執行 Linux 容器的 Docker，以及受測代理的憑證。本機初始化會建立私有的 .gauge/ 工作區，含 SQLite 資料庫與本機偏好設定。本機模式支援 Skills、SDKs、CLIs 與檔案，託管運算另支援文件、需驗證的 MCPs 與 APIs。
