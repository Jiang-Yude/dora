DeepSeek 在 GitHub 公開 dsh-superagent 研究原型

DeepSeek 在 GitHub 公開 dsh-superagent-prototype 專案，README 標示這是參考用的研究原型，並非 DeepSeek 的官方產品，程式可能有錯誤。專案以 MIT 授權釋出。

dsh-superagent 是面向單一 GitHub 儲存庫的主動式編碼代理，以 DeepSeek Harness 的套件形式封裝。它監聽 GitHub，也可選擇監聽飛書；獲授權的使用者提出工作後，它會建立工作項目，在自己的會話與目錄中處理，再回到原對話回覆，例如提供 Pull Request。設計原則是只在有人要求或團隊規則允許時行動。

README 說明，公開版本與 DeepSeek 內部版本，以及文章中的實作並不相同，文章中部分設計方向尚未實作於此原型。架構文件指出，Engine 是 Triggers、Threads、Decisions、Tickets 與 Assignments 的唯一寫入者；Passes 預設每兩秒執行一次。

2AI應用

Karpathy 用 Claude 約 2 小時做出 HackerTube

據 INSIDE 報導，Karpathy 在 X 發文表示不滿 YouTube 的推薦機制，並請 Claude 從 Hacker News 約 4,300 萬則留言中，篩出 6,454 支被反覆推薦的影片，做成網站 HackerTube。報導稱，他說整個製作過程約花 2 小時，使用的模型是 Opus 5.5。

INSIDE 指出，這些影片約分為 150 個主題；Startup Fortune 報導，留言的時間範圍是 2007 年到 2026 年。依 Startup Fortune 報導，Opus 5.5 負責建立資料擷取流程，Sonnet 在 Claude Code 的工作流程中負責留言篩選，把連結篩成最終清單。Karpathy 自述，Google Cloud API 金鑰、啟動 VPS 與購買網域是由他手動完成。

據 Startup Fortune 報導，HackerTube 不需登入，觀看狀態保存在瀏覽器，影片縮圖取自影片中段，並提供資料匯出。INSIDE 同時指出，目前公開資訊主要來自 Karpathy 本人的貼文與媒體轉述，影片品質與使用體驗尚無獨立評測。

3AI產業趨勢

OpenAI 稱 ChatGPT 搜尋查詢量達 Google 的 20%

據 The Verge 報導，OpenAI 消費端產品主管 Adam Fry 在週一的媒體活動上表示，ChatGPT 的搜尋查詢量相當於 Google 搜尋查詢量的 20%，也就是五分之一。文章指出，Fry 沒有說明 Google 搜尋量數字的來源。

Fry 說，OpenAI 把搜尋定義為使用者輸入後會觸發網路搜尋的查詢，查詞義或簡單操作說明等任務不算在內。文章提到，微軟執行長 Satya Nadella 曾在 2023 年 Google 面臨的反壟斷審判中表示，Bing 當時約占搜尋引擎市場 3%；Google 在該審判中則將 AI 描述為可能顛覆搜尋的技術，並表示 ChatGPT 有望成為嚴肅的競爭者。

Fry 將在聊天機器人回覆中建立視覺化、互動式介面的方向稱為「Intelligent UI」，並說使用者將會「對著一個畫布交談」。在廣告方面，Fry 對記者表示，廣告沒有對產品或使用量造成負面影響，大多數人似乎不介意產品中的廣告。文章稱，OpenAI 上個月宣布將開始在 ChatGPT 中展示贊助商品和服務的圖片，此前展示的是公司名稱、標誌和產品連結。

4AI產業趨勢

Google 表示拒用 AI 功能的學校將無法使用搜尋

據 The Verge 報導，Google 向《紐約時報》表示，拒絕其 AI 功能的學校將無法使用 Google 搜尋。Google 在教育更新中說明，Gemini、Gemini Notebook、Gemini in Classroom 和 Google 搜尋對 K-12 學生帳號的存取權將預設關閉，直到學校管理員明確開啟。

The Verge 報導稱，Google 沒有提供讓管理員關閉 Gemini 驅動功能、同時保留搜尋的選項。Google 教育副總裁 Chris Phillips 對《紐約時報》表示，搜尋與 AI 深度整合，禁用 AI 功能的學校會讓學生看到該服務不可用的訊息。同一篇報導也引述 Google 的說法，指這項改變讓學校有更多選擇，學校可以逐項開啟或關閉服務。

在功能面，Google 表示將於本月稍晚在部分美國學校試行把 Guided Learning 功能加入搜尋，並蒐集教育工作者意見。Google Classroom 中的 Guided Learning 已於公告當日在全球推出，學生開始教師指派的活動時，它會以課程材料為基礎協助學習，並提供教師即時課堂概況。

思科開源 AI 代理偵測工具 Project Quarry

思科（Cisco）開源 AI 代理行為偵測工具 Project Quarry。據 iThome 報導，這項工具可分析 AI 代理執行任務期間的工具呼叫、工具執行結果與各項操作的先後順序，協助資安團隊辨識可疑行為。Quarry 已在 GitHub 公開原始程式碼，標示採 Apache 2.0 授權。

據 iThome 報導，資安人員可透過專用規則語言設定偵測條件，再由偵測引擎分析 AI 代理的操作紀錄。Quarry 也可結合 AI 模型做語意判斷，例如檢查工具回傳內容是否含提示詞注入指令，或操作是否偏離原定任務。Cisco 介紹，Quarry 是結合機器學習判斷與規則檢查的偵測語言與執行引擎。

Cisco 表示，規則命中時 Quarry 會回傳相關步驟、命中的欄位及摘要片段，接收結果的產品可將結果映射為警示、封鎖、遮蔽、隔離或記錄等動作。思科表示 Quarry 已應用於 AI Defense，並計畫導入 DefenseClaw；計畫中的功能與整合可能變更。
