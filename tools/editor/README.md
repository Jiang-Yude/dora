# 朵拉排版編輯器

在真的網頁上直接拖、轉、放大縮小任何東西，雙擊文字直接改字，按「儲存」就寫回網站原始檔。
這個資料夾不在 `site/` 裡，不會被部署上線。

## 怎麼開

雙擊 `start.command`。它會在本機開一個小伺服器（只有這台電腦連得到），再用預設瀏覽器打開
http://127.0.0.1:8792/?edit=1

要停掉：關掉跳出來的終端機視窗，或在裡面按 Ctrl+C。

不想用雙擊也可以在終端機打：

```
python3 ~/Developer/dora/tools/editor/dora-editor.py
```

## 怎麼用

| 想做什麼 | 怎麼做 |
|---|---|
| 換頁面 | 左上角下拉選單（首頁、實習日記、AI 日報、搜尋，其他頁也在裡面） |
| 換裝置寬度 | 桌機 1920／筆電 1366／手機 390 三個按鈕 |
| 選一個東西 | 滑鼠移上去會出現淡藍虛線框，點一下選取 |
| 選到外面那一層 | 按住 Alt 再點，或按工具列「選上一層」 |
| 移動 | 直接拖；方向鍵微移 1px，按住 Shift 一次 10px |
| 放大縮小 | 拖四個角的方塊（等比例） |
| 旋轉 | 拖上方的小圓點（按住 Shift 每 15 度一格） |
| 打數字 | 右邊面板的 X、Y、旋轉、縮放可以直接輸入 |
| 改字 | 雙擊文字；Enter 完成、Shift+Enter 換行、Esc 取消 |
| 放回原本的樣子 | 選取後按「回原狀」 |
| 復原／重做 | ⌘Z／⇧⌘Z（或工具列按鈕） |
| 儲存 | ⌘S 或「儲存」，存完畫面會自己重新載入，看到的就是存進去的樣子 |

編輯時網頁上的連結、點開放大都不會作用，放心點。
有沒存的變更時，換頁、換裝置、離開都會先問你。

## 存到哪裡

- **位置、角度、大小**：寫進 `site/edit-overrides.css`。分桌機、筆電、手機三段，
  **只存給你當下選的那個裝置寬度**。桌機調好了，手機要切到手機另外調。
  每一頁 HTML 會自動加上一行 `<link rel="stylesheet" href="/edit-overrides.css?v=…" data-ep="頁面代號">`，
  規則只會套用在那一頁。
- **改字**：直接改那一頁的原始 HTML（只換那一段，找不到或對不上就不改，會跳錯誤）。
- **備份**：每次儲存前，要改的檔案都先複製一份到 `tools/editor/backups/日期-時間/`。
  要還原就把備份裡的檔案複製回去。

## 哪些字不能改

畫面會直接告訴你，位置、大小、旋轉還是可以調：

- **導覽列、首頁「最近 7 天」日報清單、日報翻頁**：這些是 `site/daily/build-index.py` 自動產生的，
  在這裡改字，下次重生就被蓋掉，所以不給改。
- **AI 日報目錄頁**：整頁都是自動產生的。
- **每期日報的內文、搜尋結果**：是網頁程式讀資料畫出來的，原始 HTML 裡沒有這些字，要改請改資料。

## 注意

- 存完還沒上線。要上線照原本的流程 commit、部署。
- 被調過位置的元素，原本滑鼠移上去的小動畫（例如拍立得卡片微微抬起）會被固定住。
- 原本是一行字裡的小元素（例如句子中的粗體字），要能轉、能縮放，存的時候會順便變成 inline-block。
