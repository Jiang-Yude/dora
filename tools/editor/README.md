# 朵拉排版編輯器

在真的網頁上直接拖、轉、放大縮小任何東西，雙擊文字直接改字，按「儲存」就寫回網站原始檔。
這個資料夾不在 `site/` 裡，不會被部署上線。

## 怎麼開

雙擊 `start.command`。它會在本機開一個小伺服器（只有這台電腦連得到），再用預設瀏覽器打開
http://127.0.0.1:8792/?edit=1

要停掉：關掉跳出來的終端機視窗，或在裡面按 Ctrl+C。

不想用雙擊也可以在終端機打：

```
python3 ~/Developer/dora/tools/editor/dora-editor.py
```

## 怎麼用

| 想做什麼 | 怎麼做 |
|---|---|
| 換頁面 | 左上角下拉選單（首頁、實習日記、AI 日報、搜尋，其他頁也在裡面） |
| 換預覽寬度 | 桌機 1920／筆電 1366／手機 390 三個按鈕，或在旁邊的寬度框直接打任何數字（例如 1136）按 Enter，也可以從清單挑 |
| 選一個東西 | 滑鼠移上去會出現淡藍虛線框，點一下選取 |
| 選到外面那一層 | 按住 Alt 再點，或按工具列「選上一層」 |
| 移動 | 直接拖；方向鍵微移 1px，按住 Shift 一次 10px |
| 放大縮小 | 拖四個角的方塊（等比例） |
| 旋轉 | 拖上方的小圓點（按住 Shift 每 15 度一格） |
| 打數字 | 右邊面板的 X、Y、旋轉、縮放可以直接輸入 |
| 改字 | 雙擊文字；Enter 完成、Shift+Enter 換行、Esc 取消 |
| 放回原本的樣子 | 選取後按「回原狀」 |
| 復原／重做 | ⌘Z／⇧⌘Z（或工具列按鈕） |
| 儲存 | ⌘S 或「儲存」，存完畫面會自己重新載入，看到的就是存進去的樣子 |

編輯時網頁上的連結、點開放大都不會作用，放心點。
有沒存的變更時，換頁、換寬度、離開都會先問你。

## 每個寬度各存一個錨點

按「儲存」＝把位置、角度、大小存成**目前預覽寬度**的「錨點」。在 1136 存的就是 1136 要的樣子，
之後到 900 再存，只會多一個 900 的錨點，1136 那個不會被動到。

三步驟：

1. 寬度框打 1136（或從清單挑），把東西調好，按儲存。
2. 寬度框改 900，調好，按儲存。
3. 換其他寬度看看：兩個錨點中間（例如 1000）會自動平滑過渡；比最窄的錨點還窄就照最窄的、比最寬的還寬就照最寬的。

規則細節：

- 手機（≤760）、筆電（761–1366）、桌機（≥1367）三段各算各的，不會跨段內插，因為那裡版型會換。
- 筆電段一個錨點都沒有、桌機段有：照桌機最窄的錨點 × 視窗寬度 ÷ 1366 等比例縮放（舊版的「auto」）。
- 手機段沒有錨點：維持網頁原本的樣子。
- 右邊面板會列出選取元素有哪些錨點寬度：「看」切到那個寬度，「刪除」只刪那一個寬度，其他不動。
- 上方狀態列：「目前寬度 W・這個寬度有 N 個錨點」（N＝這一頁在這個寬度存過錨點的元素數）。
- 一個元素只剩一個錨點、又按「回原狀」存檔，這個元素的錨點整條拿掉；還有其他錨點時，會存一個「原本樣子」的錨點。

## 存到哪裡

- **錨點正本**：`tools/editor/anchors.json`（不在 `site/`，不會部署）。每條＝頁面代號＋選擇器＋各寬度的 x、y、旋轉、縮放。
- **網站實際用的 CSS**：`site/edit-overrides.css`，每次存檔由 anchors.json 整份重新產生，**不要手改**（會被蓋掉）。
  每個元素前面有一行 `/* @anchor 頁面 | 選擇器 | 寬度… */`，後面每行一條 `@media(寬度範圍){選擇器{transform}}`；
  兩個錨點之間用 `calc(… 100vw …)` 線性內插，旋轉、縮放用 `tan(atan2(100vw - 起點, 區間寬))` 換成 0～1 的比例。
- 2026-10-14 從舊版（桌機／筆電／手機三段）一次性遷移：桌機→1920、1367；筆電有調的→1366、761；
  筆電沒調的→1366＝桌機值、761＝桌機值×761/1366（等於舊的 auto）；手機→760、320。
  遷移前的 CSS 備份在 `backups/20261014-211142/`。重跑遷移：`python3 dora-editor.py --migrate`（anchors.json 已存在就不做）。
- 測試：`python3 test-anchors.py selftest`（暫存複本裡模擬 1136、900 各存一個錨點，用 headless Chrome 量實際位置）；
  `python3 test-anchors.py compare 舊.css 新.css`（兩份 CSS 在 1920、1440、1366、1100、900、800、390 寬逐元素比對）。
- 每一頁 HTML 會自動加上一行 `<link rel="stylesheet" href="/edit-overrides.css?v=…" data-ep="頁面代號">`，
  規則只會套用在那一頁。
- **改字**：直接改那一頁的原始 HTML（只換那一段，找不到或對不上就不改，會跳錯誤）。
- **備份**：每次儲存（含刪錨點）前，要改的檔案（含 anchors.json）都先複製一份到 `tools/editor/backups/日期-時間/`。
  要還原就把備份裡的檔案複製回去。

## 哪些字不能改

畫面會直接告訴你，位置、大小、旋轉還是可以調：

- **導覽列、首頁「最近 7 天」日報清單、日報翻頁**：這些是 `site/daily/build-index.py` 自動產生的，
  在這裡改字，下次重生就被蓋掉，所以不給改。
- **AI 日報目錄頁**：整頁都是自動產生的。
- **每期日報的內文、搜尋結果**：是網頁程式讀資料畫出來的，原始 HTML 裡沒有這些字，要改請改資料。

## 注意

- 存完還沒上線。要上線照原本的流程 commit、部署。
- 被調過位置的元素，原本滑鼠移上去的小動畫（例如拍立得卡片微微抬起）會被固定住。
- 原本是一行字裡的小元素（例如句子中的粗體字），要能轉、能縮放，存的時候會順便變成 inline-block。
